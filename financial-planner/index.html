☁️ GitHub自動同期（推奨）

GitHubリポジトリをデータ置き場にすることで、PCとスマホが常に同じデータを参照します。
一度設定すれば、保存のたびに自動でGitHubへ書き込み・読み込みします。

✅ GitHub同期が有効です
トークン：
GitHubでトークンを発行して貼り付けるだけ。設定は自動入力されます。
🔑 Personal Access Tokenを直接入力する（上級者向け）
※ トークンはこの端末のlocalStorageにのみ保存。GitHub APIリクエスト以外には送信されません。
📲 URLシンク（GitHub未設定時の代替手段）

同期URLをコピーしてLINEで自分宛に送り、スマホで開いてインポートする手動同期方法です。

🔒 プライバシーについて
✅ データの保存先
データはこのデバイスのlocalStorageに保存されます。GitHub同期を有効にした場合は、あなた自身のGitHubリポジトリにも保存されます（第三者のサーバーには送信されません）。

✅ GitHub同期を使う場合
PCとスマホ両方でPATを設定すると、保存のたびに自動でGitHubへ書き込み、ページを開くたびに自動で読み込みます。

✅ アクセス方法
GitHub PagesのURLをブックマークすれば、いつでもどのデバイスからもアクセスできます。
🔐 PINロック設定

共有デバイスでの使用時にPINでアプリをロックできます。
