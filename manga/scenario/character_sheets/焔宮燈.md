# 焔宮燈（ほむらみや あかり）

## 基本情報
- **役割**: 主人公（protagonist）
- **初登場**: 第1章

## 外見（画像生成プロンプト用・英語）
```
teenage boy, silver-white hair with dark crimson tips, pale grey eyes with subtle red flecks,
lean wiry build, tattered grey academy uniform repaired with rust-colored stitching,
small black spiral mark on right wrist
```

## シルエット特徴
- 銀白色の髪と深紅の毛先のコントラスト（グラデーション）
- ぼろぼろだが丁寧に修繕された制服
- 右手首の黒い渦紋（呪印）— 戦闘時に赤く光る
- 細身で中肉中背、派手な装備なし

## 性格・口調
寡黙で内省的だが、一度決めたことは絶対に曲げない。皮肉屋だが根は優しい。感情が高ぶると右手首の呪印が熱を持つ。大声で叫ぶタイプではなく、静かな確信で前進する。

## 台詞のトーン例
- 「………俺のやり方で行く」
- 「（静かに）やってみないとわからない。」
- 「お前には関係ない。どけ。」
- 感情の爆発時でも短文。叫ばない。内側に火を宿す。

## 能力
- **火の呪い（炎術）**: 生来の呪印から炎を直接発動。詠唱不要。ただし制御が難しく自傷リスクあり
- **詠唱式魔法**: ほぼ使えない。呪印が詠唱回路を阻害している

## 成長アーク
第1章: 学院から排除 → 第6章: 炎術の最初の制御成功 → 第12章: 復学 → 第17章: 椎那との頂上決戦 → 第30章: 炎術と詠唱術の統合
